# Dwell Indexed RIS 논문 (IEEE/ASME T-Mech 투고용)

- `main.tex` 본문 (IEEEtran journal 2단, 최종 12쪽 이내 목표)
- `references.bib` 참고문헌 (각 항목은 웹에서 독립 출처 두 곳으로 확인됨)
- `IEEEtran.cls`, `IEEEtran.bst` IEEE 템플릿
- `figures/` 그림 폴더 (현재는 본문에 빨간 자리표시 박스로 들어가 있음)
- `archive/` 2026-08-20 T-RO용 이전 초안

빌드 순서는 pdflatex → bibtex → pdflatex → pdflatex 이고, 루트 문서는 `main.tex` 입니다.
빨간 `[...]` 표시는 아직 채워야 할 값입니다.
